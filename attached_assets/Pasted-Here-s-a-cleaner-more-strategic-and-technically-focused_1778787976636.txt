Here’s a cleaner, more strategic and technically focused version of the Replit prompt that simplifies the objective and makes the testing/staging environment clearer and easier for Replit to execute:

Please create a dedicated SNAP testing / development environment that allows the admin team to fully review, test, and quality-check the complete app experience before live deployment updates are released to production users.

The goal is to create a:

* stable staging environment
* simplified admin testing experience
* safe review process for new features and enhancements
* clearer collaboration workflow during development

---

## CORE REQUIREMENT

Create a separate:

# SNAP Staging / Development Site

This should function independently from the live production app and allow:

* feature testing
* onboarding review
* subscription testing
* wellness testing
* education pathway testing
* AI testing
* admin review
* consultant flow testing
* bug fixing and QA

This environment should mirror the live app experience as closely as possible while remaining isolated from live user activity.

* feel professional

The staging environment must:

* remain isolated from live production users

* sandbox payment/testing mode
* test notifications only
* protected consultant requests
