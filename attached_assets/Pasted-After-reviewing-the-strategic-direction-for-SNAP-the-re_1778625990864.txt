After reviewing the strategic direction for SNAP, the recommended approach is to make:

# SNAP Foundations

…the central experience layer of the platform.

This is the strongest direction both strategically and behaviourally.

The goal is NOT to rebuild SNAP or replace existing functionality.

The goal IS to:
- connect everything already built
- guide users intelligently through the platform
- improve engagement and retention
- create daily habit loops
- reduce overwhelm
- increase emotional connection
- improve subscription conversion
- position SNAP as a preventative healthy ageing ecosystem

-----------------------------------
CORE RECOMMENDATION
-----------------------------------

SNAP Foundations should become:
- the onboarding engine
- the engagement engine
- the educational engine
- the feature discovery engine
- the behavioural coaching layer
- the retention engine

This should function as:
“A guided daily healthy ageing journey.”

NOT:
- a separate app
- a replacement platform
- duplicate tracking systems
- duplicate wellbeing tools

-----------------------------------
IMPORTANT IMPLEMENTATION PRINCIPLE
-----------------------------------

Everything already built within SNAP remains valuable and should stay.

This includes:
- Nutrition Log
- Breathing Studio
- Subscription flows
- Audio experiences
- Tracking systems
- Educational content
- Mood/wellbeing tools
- Notifications/reminders
- Premium features
- Personalisation
- Community concepts
- Progress systems

The new SNAP Foundations experience should ENHANCE and CONNECT these systems through:
- behavioural design
- contextual onboarding
- progressive feature introduction
- guided journeys
- habit reinforcement

DO NOT:
- duplicate existing functionality
- create disconnected systems
- rebuild tools unnecessarily

-----------------------------------
RECOMMENDED EXPERIENCE STRUCTURE
-----------------------------------

SNAP Foundations becomes the main guided experience.

Inside Foundations, users are progressively introduced to:

- Learn
- Nourish
- Move
- Breathe
- Reflect
- Community

These should act as simple “destinations” within the platform.

This simplifies the experience and reduces cognitive overload.

-----------------------------------
EXAMPLE OF CORRECT IMPLEMENTATION
-----------------------------------

Lesson:
“Why calcium matters”

→ Introduce the existing Nutrition Log
→ Explain mg vs IU vs mcg
→ Help users confidently log calcium intake
→ Show progress gently

NOT:
❌ Build another calcium tracker

-----------------------------------

Lesson:
“Stress and bone health”

→ Introduce Breathing Studio
→ Recommend a calming breathing session
→ Explain why stress management matters

NOT:
❌ Build a separate meditation system
