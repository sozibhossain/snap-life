Please update and enhance the **existing SNAP Supplement Tracking system** (do NOT rebuild or duplicate it) to include medication tracking, dosage selection, and integration into the overall bone health scoring and insights engine.

This is an **evolution of the current feature**, not a replacement.

---

## CORE PRINCIPLE

Enhance the existing Supplement Tracker by turning it into a unified:

# “Nutrition + Medication Intake System”

This system should:

* extend current supplement tracking
* allow medication logging
* enable precise dose selection
* feed directly into the Bone Health Tracker
* improve insight generation and behavioural feedback
* remain simple and non-clinical in UX

Do NOT:

* create a separate medication tracker
* duplicate existing supplement logging
* fragment user data across multiple systems

---

1. CORE FEATURE ENHANCEMENT

---

Extend the current supplement tracking to support:

### A. SUPPLEMENTS (existing functionality — enhance only)

* Vitamin D
* Calcium
* Magnesium
* Vitamin K2
* Omega-3
* Collagen
* Multivitamins
* Protein supplements

Enhancements:

* improved dosage selection UI
* unit standardisation support (mg, mcg, IU, g)
* clearer daily intake visualisation
* easier “add dose” flow

---

### B. MEDICATION TRACKING (NEW EXTENSION INSIDE SAME SYSTEM)

---

Add ability for users to log prescribed medications alongside supplements.

Include commonly used bone-health related categories:

#### Bone Health Medications

* Bisphosphonates (Alendronic acid, Risedronate, Ibandronate)
* Denosumab
* SERMs (Raloxifene)
* Teriparatide / PTH analogues
* HRT (oestrogen-based therapies)
* Prescription Calcium / Vitamin D combinations (e.g. Adcal-D3)

#### General Support Medications (optional tracking)

* NSAIDs (Ibuprofen, Naproxen)
* Paracetamol
* Statins
* Blood pressure medication
* Thyroid medication
* Anticoagulants
* Diabetes medication

IMPORTANT:

* Users MUST be able to manually add any medication not listed
* This is NOT a prescribing system
* It is a tracking + awareness tool only
