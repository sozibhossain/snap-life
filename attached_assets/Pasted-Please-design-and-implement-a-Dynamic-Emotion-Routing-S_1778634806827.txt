Please design and implement a **Dynamic Emotion-Routing System** for SNAP’s Wellness Lounge that automatically selects the most appropriate meditation/audio session based on a user’s likely emotional state.

This system transforms the current static session selection into an **AI-guided emotional wellbeing engine** that increases engagement, retention, and emotional support.

The goal is to ensure users are always gently guided to the *right emotional state intervention at the right time*, without needing to manually choose.

---

# 🧠 CORE CONCEPT

Instead of users selecting:

* Stress Relief
* Sleep Support
* Focus & Clarity
* Confidence & Mindset

The system should:

> intelligently infer emotional state and recommend the most appropriate session automatically.

This creates a:

* personalised
* emotionally intelligent
* low-friction experience
* “always understood” feeling

---

# 🌿 EMOTIONAL STATE MODEL (CORE ENGINE)

The system should classify user state into 7 primary emotional categories:

---

## 1. Stress / Overwhelm

Indicators:

* rapid app activity
* repeated navigation switching
* incomplete actions
* high engagement volatility
* stress-related content selection

Output:
→ Stress Relief (5 min)

---

## 2. Sleep / Fatigue

Indicators:

* evening/night usage
* low interaction speed
* inactivity before session
* repeated sleep-related content

Output:
→ Sleep Support (7 min)

---

## 3. Focus / Cognitive Fog

Indicators:

* mid-day usage spikes
* task switching behaviour
* incomplete logging actions
* low clarity engagement patterns

Output:
→ Focus & Clarity (6 min)

---

## 4. Low Confidence / Self-Doubt

Indicators:

* missed streaks
* reduced logging behaviour
* hesitation in tracking features
* repeated app revisits without action

Output:
→ Confidence & Mindset (6 min)

---

## 5. Neutral / Balanced State

Indicators:

* stable usage
* consistent engagement
* no emotional spikes

Output:
→ Calm / Regulation (NEW BASELINE STATE)

---

## 6. Sadness / Worry

Indicators:

* reduced engagement
* low activity streaks
* negative behavioural patterns
* optional user self-report

Output:
→ Sadness / Worry Support (NEW)

---

## 7. Positive / Uplift

Indicators:

* streak milestones
* high engagement completion
* morning positive usage patterns

Output:
→ Happiness / Positive Lift (NEW)

---

# 🤖 AI ROUTING LOGIC

The system should use a **multi-signal inference model** combining:

## A. Behavioural signals

* session timing
* navigation patterns
* engagement depth
* streak status
* incomplete actions
* feature usage

## B. Contextual signals

* time of day
* recent session history
* day of week
* usage rhythm patterns

## C. Optional self-report input

* “How are you feeling?” quick select
* emoji-based check-in
* skip allowed (non-mandatory)

## D. Historical emotional trends

* recurring stress cycles
* sleep disruption patterns
* adherence patterns
* engagement consistency

---

# 🎯 ROUTING DECISION ENGINE

Each emotional state is assigned a weighted score.

Example:

Stress Score =

* rapid navigation switching
* incomplete tasks
* high engagement volatility

Sleep Score =

* evening usage
* low interaction speed
* inactivity prior to session

The system selects:
→ highest confidence emotional match

Fallback:
→ Calm / Regulation session (safe default)
